# Medusa

Medusa is an open-source commerce platform providing building blocks for digital commerce applications. It offers a modular architecture with customizable commerce modules that can be used to build B2B/DTC stores, marketplaces, distributor platforms, PoS systems, and service businesses.

## Key Characteristics
- Headless commerce backend with REST APIs
- Modular architecture with independent commerce modules
- Built-in admin dashboard (React)
- Extensible through plugins and custom modules
- MIT licensed, all commerce modules available on npm

## Target Use Cases
- E-commerce storefronts
- Marketplaces
- B2B commerce platforms
- Point of Sale systems
- Custom commerce solutions requiring foundational primitives
